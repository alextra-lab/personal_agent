## Proposals

At most ten. Each is for master's disposition and the owner's decision. None was executed by this seat.

1. **Do not add a `planner` mode to `gemma-4-26b-a4b` on this evidence.** It fails D7 decline-correct by
   one draw (F1). If the owner chooses Gemma, run the probe again first. The miss is one fixture, 0 of 3,
   so a second run shows whether it is the model or the draw.
2. **If Gemma becomes primary without a planner mode, measure the cost of its thinking planner first.** It
   writes 3,055 to 5,127 tokens on each fan-out turn (F3), and that configuration has never passed D7.
   Two options:
   - qualify a thinking-off planner mode (proposal 1).
   - bind the planner to a qualified deployment.
3. **Treat the quality result as a tie, not a ranking.** One replicate, one script, and the gap is inside
   scorer disagreement (F8). Gemma's advantage is speed: 2.6× less wall time on the same turns (F5).
4. **Before a switch, run s2_tool and s3_logs_learning on both models.** Gemma used about a third of the
   searches (F7), and the scorers called its research turns thinner. s1_trip does not stress tool building
   or log work, where fewer tool rounds may matter more.
5. **Watch the worker report step on Gemma.** A worker with findings in its notes returned an empty report
   once in 7 workers (F6). A second session shows whether it repeats. File a ticket only if it does.
6. **Teach the FRE-1539 checker to read `tool_call_completed` for sub-agent tools.** A successful
   sub-agent `run_python` with 0 denial events still reads "unverified" (F5), which removes a clean turn
   from the delivered rate.
7. **Quote the 2026-09-15 Flash-Next figures only with the FRE-1529 caveat** (F10), and use the control
   session as the Flash-Next reference from now on (F11).
